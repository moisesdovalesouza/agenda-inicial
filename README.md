# Agenda Inicial

Agenda de uso pessoal em estilo bullet journal: registro diário, calendário, registro futuro, listas com subtarefas, arquivos com visualizador, lembrete do ponto e PDFs.

Abra em **https://moisesdovalesouza.github.io/agenda-inicial/** no Chrome e instale como aplicativo.

Este repositório guarda apenas o programa. Os dados ficam somente no computador do usuário, na pasta `Documentos\Agenda Inicial`, e nunca são enviados para a internet.
